## Atualização das artes

Os arquivos SVG são fontes editáveis. Para gerar novamente logo otimizada, JPGs e ícones, execute `node scripts/generate-brand-assets.mjs` na pasta do projeto após instalar as dependências. O script usa o Sharp incluído nas dependências do Next.js. Ao mudar o domínio, ajuste também o texto das artes no script. Ao substituir uma arte já publicada, incremente o sufixo `v1` do arquivo e atualize `siteConfig.seo.ogImage` para evitar prévias antigas em cache.
